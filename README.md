# Genie Magnet — Agency OS

Internal operating system for Genie Magnet (built by InTouch Global Tech).

## Repo layout

| Path | What | Status |
|---|---|---|
| `apps/web` | Next.js + React web app | Frontend demo (dummy data) |
| `apps/api` | NestJS + Prisma + PostgreSQL + Redis/BullMQ + Better Auth + CASL | Planned |
| `apps/mobile` | React Native + Expo field app | Planned |

## Run the demo

```bash
npm install
npm run dev
```

Open http://localhost:3000. Use the avatar menu (top right) to switch roles or reset demo data.
